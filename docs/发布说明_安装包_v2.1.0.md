# GoDojo 围棋道场 · 安装包发布说明

**版本**：2.1.0
**安装包**：`F:\围棋\发布\GoDojo_v2.1.0_安装包.exe`（218.6 MB）
**发布日期**：2026-09-26

---

## 一、这个包是什么

一个**独立的 Windows 安装程序**，双击就能装到任意电脑上，装完直接玩，**不需要装 Python、不需要配引擎、不需要下载权重**。

和之前的"绿色版"（`发布\GoDojo\` 文件夹）的区别：

| | 绿色版(旧) | 安装包(新) |
|---|---|---|
| 分发形式 | 一整个文件夹，要手动拷贝 | **单个 exe**，双击安装 |
| 引擎 | 只带 OpenCL 版，没独显就废 | **双引擎**：GPU 优先，自动降级 CPU |
| 首次启动 | 要等 5–10 分钟调优，像卡死 | **安装时就调优好了**，启动 6 秒 |
| 开始菜单 | 需手动建 | 自动创建，可正常卸载 |
| 换台电脑 | 路径全错，得手改配置 | 相对路径 + 自动发现，开箱即用 |

## 二、包里有 220 MB，装了些什么

| 内容 | 大小 | 说明 |
|---|---|---|
| 应用程序 | 19 MB | `GoDojo.exe` + 运行库 + 前端页面 |
| KataGo GPU 引擎 | 14.6 MB | OpenCL 版，有显卡时用这个，快 |
| KataGo CPU 引擎 | 14.2 MB | CPU 版，没显卡/驱动不行时自动顶上 |
| 神经网络权重 | 201.8 MB | 两个引擎共用一份，不重复占空间 |
| GPU 调优缓存 | 1.5 KB | **关键**：带了一份开发机的，同款显卡免调优 |

## 三、安装时会发生什么

1. 选安装目录（默认 `D:\GoDojo`）。
2. 勾选「立即预热引擎」（**默认勾着，建议保留**）。
3. 装完那一刻，安装程序会调 `GoDojo.exe --warmup` 静默跑一遍引擎调优：
   - **同款显卡**（Intel Arc 130T 之类）：几秒完成
   - **别的显卡**：3–10 分钟，进度条显示「正在为显卡做引擎调优」
4. 预热结束后启动程序，**首次打开就是秒开**。

> 为什么不在程序里等？因为新机器第一次用 OpenCL 要给显卡做基准测试挑最快内核，
> 实测本机要 3.7 分钟。放在安装阶段做，用户不用盯着发呆。

## 五、本轮做的代码改进

### 1. 引擎 GPU→CPU 自动降级（新增）

`core.engine_candidates()` 按 `配置指定 → OpenCL → CPU` 列出候选，启动时逐个试，
谁先应答就用谁。别人机器没独显也不会「装完打不开」。

### 2. 首次调优的可见进度（新增）

- 探测超时按引擎类型区分：OpenCL 给 **15 分钟**，CPU 给 90 秒
  （都写在 `core.PROBE_TIMEOUT`，改起来一目了然）
- 引擎 stderr 单独收管道，认得出「tuning」字样就实时改进度文字
- `state()` 新增 `engine.progress`，前端橙色徽标 + 状态行显示「正在为显卡做首次调优…已等待 N 秒」

### 3. 进程早死立即返回（修 bug）

原来 `_probe` 不管进程死活都等满超时。现在进程一退立刻返回 —— 降级场景从 40 秒缩到 5.3 秒。

### 4. 引擎启动诊断透明化（新增）

`Engine.notes` 记录每个候选的失败原因（进程退出码 + stderr 最后 3 行），
通过 `state().engine.tries` 透给设置页，不再只是「引擎启动失败」。

### 5. `--warmup` 模式（新增）

`GoDojo.exe --warmup` 不开窗口、不启服务，只做调优后退出。
结果写进安装目录的 `warmup.result`（因为 exe 是 `--windowed` 打包的，
安装程序读不到 stdout）。

### 6. 三处隐蔽 bug 修复

| 问题 | 后果 | 修法 |
|---|---|---|
| `_reader` 被定义了两次 | 后者覆盖前者，探测直接崩 | 删掉重复定义 |
| 探测期间 `self.p` 还是 `None` | `write()` 空指针 | `write(cmd, p=...)` 显式传进程 |
| 换候选时新队列被旧线程污染 | 读到上一轮引擎的输出 | 队列按轮次绑定传给读线程 |

## 六、给别人安装时要注意

1. **别装到 `C:\Program Files`**。KataGo 要把调优缓存写在安装目录里，
   受保护目录写不进去 → 每次启动都重新调优。安装程序默认避开它。
2. **杀毒软件可能拦 `katago.exe`**（AI 推理程序容易被误判）。
   报错了让用户加白名单。
3. **CPU 版跑 19 路建议 4 GB 以上空闲内存**。
4. 装到 U 盘也行，但**每台新电脑的第一次都要重新调优**。

## 七、后续改进的想法（未做）

- **代码签名**：现在没有数字签名，Windows SmartScreen 会提示「未知发布者」。
  要买证书（约 ¥1000/年），暂时没做。
- **多语言**：安装界面现在全中文。
- **增量更新**：现在换版本要重下 220 MB，权重没变本可以只更新程序（19 MB）。
- **GPU 型号自动匹配调优缓存**：现在是「文件名匹配就命中」，理论上可以把
  主流显卡的调优文件都带上，但会显著增大包体。

## 八、如何重新编译

```powershell
# 1) 改代码后重新打包应用(D 盘构建目录)
cd D:\GoDojoBuild
D:\GoDojoBuild\venv\Scripts\pyinstaller.exe --noconfirm --distpath dist2 --workpath build2 GoDojo_dist.spec

# 2) 重新组装载荷(引擎 + 权重 + 配置)
D:\Anaconda3\python.exe D:\GoDojoBuild\build_payload.py

# 3) 编译安装包
& "C:\Users\32524\AppData\Local\Programs\Inno Setup 6\ISCC.exe" D:\GoDojoBuild\GoDojo_setup.iss

# 产物: D:\GoDojoBuild\installer_out\GoDojo_v2.1.0_Setup.exe
```

**改版本号**：编辑 `GoDojo_setup.iss` 顶部的 `#define APP_VERSION`。

**构建相关文件**：

| 文件 | 作用 |
|---|---|
| `src_dist\` | 构建源（= F 盘 `webapp\` 的镜像 + 前端资源） |
| `GoDojo_dist.spec` | PyInstaller 打包脚本 |
| `build_payload.py` | 组装引擎/权重/配置成载荷 |
| `GoDojo_setup.iss` | Inno Setup 安装脚本 |
| `sim_install.py` | 本地模拟安装（不跑安装程序，直接铺文件） |
| `test_install.py` | 安装后端到端功能测试 |

## 九、卸载

开始菜单搜「GoDojo」→ 右键卸载，或「设置 → 应用」里找。
卸载会清掉程序、引擎、调优缓存，**保留 `games\` 里的棋谱**。
