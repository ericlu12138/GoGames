# 外接 AI 对局接口(GoDojo)

## 这是什么
让**任意 AI**(ChatGPT / Claude / 另一个 DSH 智能体 / 你自己写的脚本)来跟 GoDojo 内置的
KataGo 引擎对局。交流方式是**两个文本文件**:

| 文件 | 谁写 | 内容 |
|---|---|---|
| `position.txt` | 软件写 | 当前局面(棋盘图 + 着法历史 + 空点列表) |
| `ai_move.txt`  | **外接AI写** | 它的下一手,例:`E5`(停一手写 `pass`) |
| `ai_error.txt` | 软件写 | 若外接AI的着法非法,这里给出原因 |

## 使用流程
1. 打开 GoDojo → 顶部「对手」下拉选 **外接AI(文件)** → 选好「棋盘」「你执」
2. 轮到外接AI时,软件会刷新 `position.txt`,并在状态栏提示"⏳ 轮到外接AI"
3. 把 `position.txt` 的内容发给外接AI,让它给出着法
4. 把它的着法写进 `ai_move.txt`(只写坐标,如 `E5`)
5. 软件读到后自动落子,局面继续推进

## 给外接AI的现成提示词(可直接复制)
见同目录 `prompt.txt`。

## 规则
- 默认 9 路,贴目 7.5,中国规则数子
- 标准打劫(禁止全局同形再现)、禁止自杀手
- 坐标:列 A-J(9路,跳过 I),行 1-9(从下往上)
