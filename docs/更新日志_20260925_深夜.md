# GoDojo 更新日志 · 2026-09-25 深夜(终端弹出修复)

## 问题:运行期间终端窗口一直弹出,影响使用

**现象**:启动 GoDojo 后,黑色终端窗口反复闪现(用户截图确认)。

**根因**(两个,都已修复):

1. **每 2 秒一次的 `tasklist` 弹窗**
   前端轮询引擎状态时,后端反复运行 `tasklist`(控制台程序)。
   源码运行时它继承终端不弹窗;但打包成无窗口 exe 后,
   **每次运行都闪一个黑色终端**——这就是"一直弹出"的主力。

2. **katago 引擎的常驻控制台**
   `katago.exe` 是控制台程序,启动时会开一个黑色终端窗口挂在任务栏。

**修复**:所有子进程调用统一加 `CREATE_NO_WINDOW` 标志
(`core.py` 的进程探测/清理/引擎启动,`app.py` 的浏览器启动)。

**验证**(实机,2026-09-25 23:14):

| 验证项 | 结果 |
|---|---|
| katago 进程可见窗口 | 无 ✅ |
| 完整对局(人下 E5 → AI 应 C4) | 正常 ✅ |
| 15 秒持续状态轮询期间控制台窗口 | 0 个 ✅ |
